# Linux Server Administration

## Project: Nginx Reverse Proxy

### Technologies
- Ubuntu 24.04 LTS
- WSL2
- Nginx
- OpenSSL
- UFW Firewall
- SSH

### Implementations
1. Configured Nginx reverse proxy.
2. Enabled Gzip compression.
3. Implemented rate limiting.
4. Configured static resource caching.
5. Enabled HTTPS using a self-signed SSL certificate.
6. Configured firewall ports 22, 80 and 443.
7. Verified SSH key-based authentication.
